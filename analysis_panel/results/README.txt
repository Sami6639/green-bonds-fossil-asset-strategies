SOURCE-LINKED DESCRIPTIVE CAPACITY RESULTS

Run
python build_capacity_results.py
Optional: python build_capacity_results.py --panel-dir /path/to/analysis_panel
The script reads canonical inputs from analysis_panel and writes only beside itself. It does not read original absolute paths retained in provenance. Therefore a copied analysis_panel/results folder and copied canonical inputs are relocatable. It does not alter regional files, build_panel.py, the admission queue, or canonical outputs. No network access or additional packages are needed.

Status and authority
This is the descriptive results layer for the final audited source-defined snapshot, with qualified proxy extensions explicitly separated; no manuscript is included. The explicit analysis_evidence_tier and principal_analysis_include/matched_proxy_extension_include/broad_matched_include fields control the principal-versus-proxy hierarchy. admitted alone describes the broad source-supported screen and must not be used as a synonym for principal. SPIC unmatched physical context is outside these matched tables. Each run copies admitted/admission_status/admission_basis from the audited candidate_adjudication_queue.csv. Eligibility and measurement boundaries reflect the final source-definition audit for this snapshot. Input SHA256 values and script hash are in results_build_manifest.json. Rebuild after any canonical refresh; do not mix different build manifests. No group count is hardcoded. fossil_boundary_review.csv is the portable, hashed copy of the independent boundary audit. The fuel-identified sensitivity uses that file’s eligible flag and leaves main admission unchanged; its reasons distinguish unresolved thermal composition, unsplit cogeneration, explicitly fuel-defined capacity, fossil-capable subsets and limited segments/geographies. CLP is explicitly labelled as Green Bond Principles-aligned New Energy finance; separate broad and principal descriptive cohorts exclude this legal-label case. This label check does not independently certify every other instrument label.

Main display
One deterministic selected window per utility group label is retained. The audited longest_reviewed_window_display.csv controls the reviewed eligible window universe. If that display has more than one date interval for a group, the selector uses longest actual calendar-day duration, latest ending date, stronger finance-date resolution, then lexical source/ID tie-break; it never uses direction or magnitude. Same-window categories are dependent components. The final canonical ESB principal measure is the audited coal-plus-gas named subset, using the same reported-installed table across geographies; oil is excluded because an opening value is unknown. This is not all-fossil capacity. Its separate wind/hydro RE component windows do not establish a complete RE total, so that aggregate remains blank, not zero. The JV ownership note at wind is not generalized to fossil rows; original raw ownership labels remain inspectable beside the selected-window basis adjudication. Source-reviewed scalar bridges control when available; this layer does not newly add geography totals. Within an already-reviewed endpoint vector, only disjoint, identical-unit, identical-scope and ownership components are summed. Source rounding is retained.

This is a partial-technology sensitivity, not total RE. The coverage file reports the current observed denominator

Boundary interpretation
The outstanding_identified_bond_liability class is not uniform principal: JSW includes carrying value and Statkraft a reported lower bound. Values are retained individually and never added.
The reported-source boundary includes the selected source's RE definition or a labelled hydro/storage-inclusive proxy. It may contain conventional hydro, pumped storage, biomass, mixed waste, or commissioning conventions; it is not silently recoded as fully operating storage-free RE. The strict-storage-excluded subset is deliberately conservative and limited to affirmative exclusion evidence in retained source notes. Missing strict cells mean unverified or unavailable, not that a company has no renewables or that its reported number is false. Source-defined biomass renewable capacity can remain in this storage-excluded subset; it does not imply zero-emission generation. Fossil categories can include cogeneration, dual-fuel capability or biomass co-firing. No fuel-input apportionment or total thermal-to-fossil equivalence is assumed. In the copied audit, unresolved thermal composition is not asserted to contain standalone biomass unless a source proves that inclusion. Fossil-capable coal nameplate can remain valid despite co-firing; this says nothing about fossil-fuel output shares.

Iberdrola’s principal EBITDA-consolidated vector is the identified coal-plus-CCGT subset. The original EBITDA-consolidated vector including unsplit cogeneration is retained separately, and neither is replaced with the older consolidated-plus-proportional total. Hydro includes pumping and Solar & Other is compound; its RE is a proxy. SSE's nested 2022–2024 renewable comparison is source-definition reviewed, same-definition cross-vintage and storage-inclusive. Its wholly-owned/JV renewable perimeter differs from the thermal segment plus 100% Marchwood PPA, so no RE/fossil share is calculated. Duke's solar-only partial measure and hydro-inclusive reported proxy are separate; unchanged coal stock does not negate the documented Allen closures.

Event interpretation
The opening capacity stock is excluded from the event interval: an event must lie after the opening date and at/before the closing date to be wholly in-window. Date-overlapping uncertain records remain visible but do not create confirmed presence flags. Ownership/share/dispatch exits, reported physical closures, and operational cessation/reserve are separated. Missing documented presence means not documented in this bounded extract, never zero events. Pending sales and construction are not completed ownership exits or commissioned assets. Capacity decline cannot be converted into retirement MW, and acquisition of an existing plant is not new construction.

Descriptive limits
No generation replaces capacity; no missing value is zero-filled. No aggregate MW is summed across utility groups or incompatible bases. Only direction counts summarize across groups; cross-group median MW magnitudes are omitted because bases and durations differ. No annualized rates are pooled. No p-values, population prevalence, green-finance causal effects, or pseudo-independent counts are reported. Strict and broader summaries have different evidence denominators, not treatment/control groups. Outcomes are at reported source precision; tiny movements and rounding require the declared sign-band sensitivity.
