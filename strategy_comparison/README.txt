Strategy comparison: additive source-frozen analysis

Purpose
Compare the seven companion instrument histories on the same documentary questions and cross-tabulate selected-window fossil-capacity direction against nonexclusive documented asset-event families. This addendum does not change the established 37 = 33 principal + 4 proxy-extension cohorts, paired denominator 32, windows, or figures. Companion histories are dependent within-group evidence, not seven extra independent observations.

Reproduction
Requires Python 3 and pandas. From this directory run:
  python build_theory_evidence.py
The default uses the included frozen_inputs/ extracts. To reproduce against the original release, run:
  python build_theory_evidence.py /path/to/global_utility_analysis_release_v2
All outputs are written beside the script. Neither route modifies the release. validation_and_provenance.json records input hashes, output hashes, handcoding hash, and regression checks. The frozen inputs are byte-for-byte copies of the referenced release CSVs, not newly downloaded or independently reverified source documents. Original documentary URLs and page locators remain in the evidence files.

Files and interpretation
seven_history_handcoding.csv is transparent analyst-authored documentary coding, not automated text inference. build_theory_evidence.py expands its source bundles to row-level provenance, validates existing cohort membership and event-presence mappings, and recomputes SSE/WEC allocation-weighted achieved-stage shares. The handcoded comparison should be read jointly with seven_history_row_provenance.csv; narratives are not generated by a causal model.
seven_history_comparison.csv: one row per companion history; scope/dates, amount, membership, weights, achieved implementation, ownership/control, explicit documentary connections, unresolved/noninferences, evidence IDs, original source URLs.
seven_history_row_provenance.csv: release-relative source filename and CSV row (header is row 1), original source URLs and complete retained row JSON. A source-row bundle supplies supporting context; not every row independently proves every cell.
principal33_direction_event_presence_long.csv: one principal group × one event family, with documentary presence or not_documented_unknown. Contains 264 rows, not 264 independent observations.
principal33_direction_event_crosstab.csv: 24 direction×family cells, each with its 20/9/4 group denominator and explicit unknown complement.
principal33_direction_event_compact.csv: numeric convenience table only; zeros mean no documented presence, not event absence. Do not present without this caveat.
principal33_selected_window_event_evidence.csv: 97 retained event rows including uncertain timing and coverage statements; only wholly-within, non-coverage rows enter presence counts.
event_family_fuel_scope_audit.csv: original direct fuel/technology descriptors plus contextual fields. Missing direct fuel descriptors remain unknown, not fossil inferred from issuer identity. Categories cover all retained asset types, not solely fossil facilities.
recomputed_allocation_stage_comparison.csv: source-matched stage/weight arithmetic, with different instrument cutoffs and currencies kept separate.

Cross-tab definitions
Directions use exact signed change in each selected source-defined total fossil-capacity boundary. They are not materiality bands or coal-only directions. Duke is a total-fossil decrease of 6 MW even where its coal subtotal is unchanged. The principal distribution is 20 decrease, 9 increase and 4 unchanged-at-reported-precision groups.
A documented event-family presence requires at least one retained event wholly after the opening date and on/before closing date. Multiple events from the same group/family count once. Overlapping/uncertain dates do not qualify. Families are nonexclusive, and all documentary nonpresences remain unknown because search coverage is bounded. Planned/pending/construction is a separate family, never achieved operation. Cessation/reserve includes status observations, not exclusively within-window reserve transitions. Family presence neither reconciles endpoint MW nor explains them causally. Do not call these stable firm types, managerial intentions, mechanisms, or population frequencies.

Important label correction
The existing event-family mapping includes nonfossil assets. In particular Colbun's sole ownership-exit event, Carena (18edfb729f21d52723fe), is hydro; AES Brasil and NextEra renewable disposals are also retained alongside those companies' fossil exits. The all-asset ownership-exit count is 8. Calling that count 8 fossil ownership exits is unsupported. Relabel to documented asset-event families alongside fossil-capacity direction; do not silently convert to a fossil-only census. Constellation's closure is Mystic Units 8–9 (gas); the documented closure count of 11 is not changed by this correction.

Limits
Same financial identity, repeated amount, recurring project names, constant monetary weights, achieved operation, and retained corporate control are distinct observations. No financial additionality, managerial intent, causal effect, financing-to-fossil-retirement link, or constant ownership/perimeter is inferred. The core comparison uses frozen records; two supplemental Enel closing releases were separately checked during this revision. See the supplemental ownership-source note below.
